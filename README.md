# My Bibliotec List

My Bibliotec List é um sistema simples de gerenciamento de livros online, permitindo que você:

- Adicione livros com título e autor.  
- Atualize ou remova livros existentes.  
- Busque livros por título.  
- Abra buscas do livro na web.  
- Volte ao topo da página com uma seta flutuante.  

O projeto utiliza **HTML, CSS e JavaScript** para a interface e faz requisições a uma API para CRUD de livros.

---

## Funcionalidades

1. **Listar livros:**  
   Exibe todos os livros cadastrados na API.

2. **Adicionar livros:**  
   Permite adicionar um novo livro, evitando títulos duplicados.

3. **Atualizar livros:**  
   Possibilita alterar título e autor de um livro existente.

4. **Remover livros:**  
   Remove livros da lista e do banco de dados.

5. **Buscar livros:**  
   Filtra os livros pelo título digitado no campo de busca.

6. **Ver livro na web:**  
   Abre uma pesquisa do livro no Google.

7. **Seta "voltar ao topo":**  
   Um botão aparece quando a página é rolada, permitindo voltar ao início.

---

## Tecnologias Utilizadas

- **HTML5** – Estrutura da página  
- **CSS3** – Estilo, cores e efeitos visuais  
- **JavaScript** – Lógica do CRUD e interação com a API  
- **Fetch API** – Comunicação com o backend  
- **API REST** – Para gerenciamento de livros
